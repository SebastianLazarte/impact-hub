# Catalog: specification

Status: **Approved** (<date of step 4>)
Pack: `packs/catalog`
Criteria: IH-22

## 1. Purpose
The barriers the [impact](impact.md) rules choose from.

## 2. Barrier
A **barrier** has a name, an application (the list of [impact.md](impact.md) section 2),
a deflection at maximum energy in mm, and one or more tested energies, each at a test
angle. How a barrier is rated for a hazard point is in impact.md section 4.

## 3. Catalog data (IH-22)
The catalog is data, not spec. In this iteration it is fictional, read-only and seeded,
every barrier in it is tested at 45° and at 90°, and every page that shows it says "example values, not manufacturer data" (C4).
